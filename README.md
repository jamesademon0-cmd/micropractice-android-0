# ToolBox Android

An original Android toolbox inspired by the interaction patterns of modern multi-tool apps. This project is not affiliated with or a copy of any third-party application.

## V0.1 scope
- Jetpack Compose + Material 3
- Glass / light-card visual system
- Home, categories, search, favorites and settings shells
- Extensible ToolDefinition registry
- First local tools: random password, JSON formatter, unit converter, text counter, QR placeholder

Reference research: public listings for the third-party app `com.magicalstory.toolbox` and its public web app. The reference app currently lists 250+ tools and version 0.5.3 on Xiaomi/Flyme stores; its web app exposes 171 online tools. See official/public sources linked in project notes.
